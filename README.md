# Emergency-Alert-System

# Project title

Emergency Contact and Alert System

# Overview of the project

This is a simple console-based Python application designed to manage emergency contacts and send customized alert messages to all saved contacts. It also logs recent activity for quick reference. Primarily intended to help users notify their trusted contacts during emergencies.

# Features
-> Add, view, and delete contacts.

-> Trigger a predefined or custom alert to all contacts.

-> Log of recent alert messages and actions.

-> Menu-driven, beginner-friendly interface.

# Technologies/tools used

-> Python 3.x (Standard Library modules: datetime, time)

-> No external dependencies required

(Optional for enhancement: json module for persistence)

# Steps to install & run the project

-> Ensure Python 3.x is installed on your computer.

-> Download the script (emergency_system.py).

-> Open a terminal and navigate to the folder containing the script.

-> Run:
python emergency_system.py
